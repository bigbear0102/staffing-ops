Staffing Ops MVP

즉시 검수 가능한 MVP 런치 페이지

운영팀용 admin 흐름 스냅샷과 pilot proof JSON을 한 곳에 모았습니다. 아래 링크에서 주문 생성, 배치 override, 출근 승인, 청구 handoff 준비 상태를 바로 확인할 수 있습니다.

핵심 검수 경로 `Order -> Placement -> Attendance -> Billing`
가장 먼저 볼 화면 Work Queue와 Billing Ready
증빙 파일 Pilot proof summary / full bundle JSON

Admin Snapshot

01. Work Queue Desktop

운영팀 triage 시작 화면과 blocker 중심 KPI를 확인합니다.

02. Work Queue Mobile

모바일 기준 큐 진입 화면과 compact 요약 구성을 확인합니다.

03. Demand Draft

상업 조건 blocker가 남아 있는 주문 초안을 봅니다.

04. Demand Publish Ready

출고 가능한 주문 상태로 unblock된 화면입니다.

05. Demand Published

주문이 staffing-ready 상태로 전환된 결과를 확인합니다.

06. Placement Selected

override가 필요한 후보 선택 단계와 blocker 문맥을 봅니다.

07. Placement Override Armed

관리자 사유 입력 후 commit 가능 상태가 된 순간입니다.

08. Placement Committed

override commit 후 배치가 확정된 결과를 확인합니다.

09. Attendance Review

재무 영향이 있는 출근 예외가 아직 검토 중인 상태입니다.

10. Attendance Approved

출근 승인 후 billing draft가 풀리는 상태를 보여줍니다.

11. Billing Ready

승인 완료 후 청구 handoff 준비 화면을 확인합니다.

Proof JSON

Pilot Proof Summary

핵심 trace, export batch, 권한 차단 proof의 요약본입니다.

Pilot Proof Bundle

감사 로그와 export artifact까지 포함한 전체 증빙 JSON입니다.

이 페이지는 `artifacts/demo-bundle/` 정적 산출물을 바로 열 수 있도록 만든 로컬 런치 인덱스입니다.
